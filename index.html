DAY 01 · C++ FOUNDATION

第一关：认识 C++ 程序

目标：读懂程序结构，并能独立写出最基础的输入输出。

1. 一个最基础的 C++ 程序

#include <bits/stdc++.h> using namespace std; int main() { cout << "Hello CSP!" << endl; return 0; }

记住：main 是程序入口；cin 负责输入；cout 负责输出；每条普通语句通常以分号结束。

2. 变量：给数据找一个盒子

int：整数；long long：范围更大的整数；double：小数；char：单个字符；string：字符串；bool：真假。

int age; cin >> age; cout << age << endl;

输入多个变量：cin >> a >> b;

3. if 判断：让程序做选择

if (score >= 60) { cout << "Pass"; } else { cout << "Fail"; }

注意 == 是比较是否相等，= 是赋值。不要混淆。

4. for 循环：重复执行

for (int i = 1; i <= 5; i++) { cout << i << endl; }

依次理解三部分：从哪里开始；什么条件下继续；每轮结束后怎么变化。

5. 累加与计数

int sum = 0; for (int i = 1; i <= n; i++) { sum = sum + i; }

累加器先初始化为 0；计数器也先初始化为 0，满足条件时再加 1。

学习方法：先合上讲解，尝试自己复述每段代码的作用，再进入练习。不要只看懂就算学会。

第 1 题 · 基础

求 1 到 n 的偶数之和

输入一个正整数 n，输出 1 到 n（含 n）之间所有偶数的和。

输入样例
10
输出样例
30

提示：循环遍历每个数，判断它是否为偶数，再累加。

第 2 题 · 进阶

统计及格人数

输入 n，接下来输入 n 个成绩。输出成绩大于等于 60 的人数。

输入样例
5
80 55 90 45 60
输出样例
3

提示：设置 count，每次遇到及格成绩就加 1。

第 3 题 · 挑战

求最大值与最小值

输入 n，接下来输入 n 个整数。输出最大值和最小值，中间用空格隔开。

输入样例
5
3 8 1 9 4
输出样例
9 1

提示：用第一个输入值初始化最大值和最小值，再逐个比较更新。
